# DevForge

It is a basic website where students can post their coding projects, share github links, and view what others are making. 

### What it does:
- Add a new project with title, description, and language used
- View all submitted projects on the home page
- Open a project to see full details and links
- Edit or delete projects (implements CRUD operations)
- Simple discussion and profile pages

### Technologies:
- HTML / CSS
- PHP
- MySQL

### Setup:
1. Import `database.sql` into MySQL Workbench.
2. Put the `devforge` folder inside `C:/xampp/htdocs/`.
3. Open XAMPP Control Panel and start Apache and MySQL.
4. Open your browser and go to `http://localhost/devforge/index.php`.
